# リール分析スキル セットアップガイド

参考にしたいリール・ショート動画をGeminiに読ませて、フック・構成・テロップ・Bロール・音の「型」を取り出すスキルです。準備は1回だけ。以下を上から順にやれば使えるようになります。

## 1. できること・できないこと

できること。

- パソコンに保存した動画ファイル（mp4・mov・webm・m4v）を分析する
- 冒頭3秒のフック、構成のブロック分け、テロップの出し方、Bロールの切替、カットのテンポ、音の使い方を、時刻付きで受け取る
- 「この動画から学べる型」と、自分の動画への転用案をもらう

できないこと。

- InstagramやYouTubeのURLをそのまま渡すこと（動画ファイルが必要です）
- 秒数を正確に測ること（出てくる時刻は概数です。編集点としてそのまま使わないでください）
- 動画を作ること、字幕ファイルを書き出すこと

## 2. 費用の目安

Gemini APIは使った分だけの後払い（または前払い残高からの引き落とし）です。動画1秒あたり、低解像度でおよそ100トークンを使います。

ぼくの環境で実際に測った数字です。

| 動画 | 設定 | トークン数 | 概算 |
|---|---|---|---|
| 20秒 | 低解像度 | 約3,400トークン | 1円未満 |
| 39秒 | 高解像度 | 約14,000トークン | 約2.8円 |

1本あたり数円です。ただし高解像度は料金が上がるので、細かい文字を読ませたいときだけ使ってください。単価は変わることがあるので、正確な金額はGoogleの料金ページで確認してください。

## 3. Gemini APIキーを取る

Gemini APIキーは、Google AI Studioで自分のGoogleアカウントから発行します。

1. ブラウザで https://aistudio.google.com/apikey を開きます。
2. 「Get API key」または「Create API key」を押します。
3. 表示されたキーをコピーします（この画面でしかコピーできないことがあります）。

画面の作りは変わることがあります。ボタンの名前が違っていたら、画面の案内に従ってください。公式の手順はこちらです。

- APIキーの取得: https://ai.google.dev/gemini-api/docs/api-key
- 支払い設定: https://ai.google.dev/gemini-api/docs/billing

### 支払い設定と上限

無料枠で使えるかどうかはモデルや時期で変わるので、Googleの料金ページで確認してください。ぼくは前払いで使っています。続けて使うなら支払い設定を済ませてください。公式ドキュメントでは、AI Studioの「API keys」または「Projects」ページの「Set up billing」から設定し、支払い方法として「Prepay」（前払い・最低750円ほど）か「Postpay」（後払い）を選ぶ、と案内されています。

**使いすぎが怖い人は、上限を必ず設定してください。** 公式ドキュメントに書かれている上限設定は、AI Studioの「Spend」ページにある「Monthly spend cap」（月の上限）です。「Edit spend cap」から金額を入れます。

ぼくの設定例です。前払いで5,000円ぶんを入れ、上限を2,000円に設定しています。この金額を超えると止まるので、想定外の請求になりません。

## 4. キーをパソコンに置く

**取得したキーは、チャット・Discord・スクリーンショットに貼らないでください。** キーは「自分のGoogleアカウントで料金が発生する鍵」です。他人に渡ると勝手に使われます。

### Macの場合

ターミナルを開いて、次を1行ずつ実行します。`ここにキーを貼る` の部分を、コピーしたキーに置き換えてください。

```
cat > ~/.gemini_api_key <<'EOF'
ここにキーを貼る
EOF
chmod 600 ~/.gemini_api_key
```

`chmod 600` は「自分だけが読めるファイルにする」という意味です。必ず実行してください。

キーチェーンでの管理に慣れている人は、こちらでも動きます。

```
security add-generic-password -a "$USER" -s gemini-api-key -w
```

### Windowsの場合

次のどちらかです。

環境変数に入れる方法（おすすめ）。

1. 「設定」→「システム」→「バージョン情報」→「システムの詳細設定」→「環境変数」を開きます。
2. 「ユーザー環境変数」の「新規」を押します。
3. 変数名に `GEMINI_API_KEY`、変数値にコピーしたキーを入れて、OKを押します。
4. 開いているアプリを閉じて、開き直します（環境変数は起動時に読まれます）。

ファイルに入れる方法。

メモ帳で新しいファイルを作り、キーだけを1行書いて、`%USERPROFILE%\.gemini_api_key` という名前で保存します（文字コードはUTF-8）。保存画面で「ファイルの種類」を「すべてのファイル」にしないと、末尾に `.txt` が付いて認識されません。

## 5. スキルをパソコンに置く

配布されたzipを展開すると `reel-gemini-analysis` というフォルダが出てきます。このフォルダを、次の場所に丸ごと置きます。

- Mac: `~/.claude/skills/reel-gemini-analysis/`
- Windows: `%USERPROFILE%\.claude\skills\reel-gemini-analysis\`

`skills` フォルダがなければ、自分で作ってください。

### Pythonが入っているか確認する

Macはターミナルで次を実行します。バージョンが表示されればOKです。

```
/usr/bin/python3 --version
```

Windowsは https://www.python.org/downloads/ からインストールします。インストール画面で **「Add python.exe to PATH」にチェックを入れてから** 進めてください。終わったらコマンドプロンプトで確認します。

```
python --version
```

## 6. つながるか確認する

Macのターミナル（Windowsはコマンドプロンプト）で実行します。

Mac。

```
/usr/bin/python3 ~/.claude/skills/reel-gemini-analysis/scripts/analyze_video.py --check
```

Windows。

```
python %USERPROFILE%\.claude\skills\reel-gemini-analysis\scripts\analyze_video.py --check
```

`接続OK：APIキーは有効です。動画の分析を実行できます。` と出れば準備完了です。動画は送られていないので、料金はかかりません。

## 7. 使い方

Claude Codeを開いて、分析したい動画のパスを添えて頼みます。

```
このリール分析して ~/Desktop/sample.mp4
```

Claude Codeがスキルを読み込んで、スクリプトを実行し、結果を要約して返します。

分析結果のファイルは、動画と同じフォルダに `<動画名>_analysis.md` という名前で保存されます。中身は、Geminiの回答の原文と、自分で映像を確認した内容を書き込む表です。

## 8. よくあるエラーと対処

| 出てきたメッセージ | 原因 | やること |
|---|---|---|
| APIキーが見つかりません | キーを置いていない、置き場所が違う | 手順4をやり直す。Windowsは環境変数を入れたあとアプリを開き直す |
| APIキーが正しくないか、まだ有効になっていません | キーの貼り間違い、支払い設定が未完了 | キーをコピーし直す。手順3の支払い設定を確認する |
| 残高または利用上限に達しています | 前払い残高切れ、上限に到達、無料枠の回数制限 | AI Studioの支払い設定で残高と上限を確認する。無料枠なら時間をおく |
| 動画が大きすぎます | 2GBを超えている | 動画を短く切るか、書き出し設定を軽くする |
| python が見つかりません（command not found） | Pythonが未インストール、PATHに入っていない | 手順5でインストールし直す。Windowsは「Add python.exe to PATH」を忘れずに |
| この形式には対応していません | mp4・mov・webm・m4v 以外 | 動画をmp4に変換してから渡す |

## 9. 注意

- 分析に出てくる秒数は概数です。カット点やテロップの表示時間を、数字のまま設計に使わないでください。
- 気になった箇所は、必ず自分の目で映像を確認してください。Geminiは読めなかった文字を「読めず」と書きますが、見落としもあります。
- 他人の動画をそのまま真似しないでください。使うのは「型」だけです。
- アップロードした動画は、分析が終わるとGemini側から自動で削除されます（`--keep-remote` を付けたときだけ残ります）。
- 人に見せられない動画、依頼主から預かった未公開素材は、送ってよいか確認してから渡してください。
